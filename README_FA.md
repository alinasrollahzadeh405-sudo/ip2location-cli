# ابزار خط فرمان ip2location-cli 🚀

[English README](README.md)

ابزار `ip2location-cli` یک اسکریپت سبک، حرفه‌ای و بدون مانع بر پایه پوسته (Bash CLI) است که برای توسعه‌دهندگان، مهندسان شبکه و مدیران سیستم طراحی شده است. این ابزار به شما اجازه می‌دهد در سریع‌ترین زمان ممکن، اطلاعات جغرافیایی IP، مشخصات ISP و بررسی‌های امنیتی (مانند تشخیص پروکسی و VPN) را مستقیماً از طریق ترمینال و با استفاده از API بدون کلید IP2Location انجام دهید.

بدون نیاز به ساخت اکانت. بدون نیاز به کلید API. بدون پیچیدگی‌های رابط کاربری گرافیکی. خالص، سریع و قدرتمند در خط فرمان.

---

## ✨ ویژگی‌های کلیدی

- **🔑 دسترسی بدون مانع (Zero-Barrier):** کاملاً بر اساس درخواست‌های Keyless کار می‌کند؛ یعنی نیازی به ثبت‌نام، ایجاد حساب کاربری یا تنظیم کلیدهای سخت‌افزاری و نرم‌افزاری ندارد.
- **⚡ نصب و اجرای تک‌خطی:** نیازی به فرآیندهای طولانی کلون کردن نیست؛ با یک دستور ساده می‌توانید آن را دریافت و اجرا کنید.
- **🛡️ هوش امنیتی و تشخیص تقلب:** شناسایی وضعیت پروکسی، وی‌پی‌ان و اطلاعات مربوط به ریسک شبکه جهت تحلیل‌های سریع.
- **🧼 خروجی انعطاف‌پذیر:** می‌توانید بین جیسون مرتب و خوانا با `jq` (پیشنهادی) یا خروجی خالص و دست‌نخورده‌ی سرور یکی را انتخاب کنید؛ خروجی خام برای پایپ (Pipe) کردن به ابزارهای دیگر و اسکریپت‌های لاگ‌گیری عالی است.
- **🧾 حالت تعاملی یا آرگومانی:** آی‌پی را هنگام پرسش وارد کنید، یا مستقیم به‌صورت آرگومان بدهید تا برای استفاده‌ی سریع و اسکریپت‌نویسی راحت‌تر باشد.
- **✅ اعتبارسنجی ورودی:** قبل از ارسال هر درخواست، فرمت IPv4 و IPv6 بررسی می‌شود.
- **🧯 مدیریت خطای قدرتمند:** قطع اتصال، تایم‌اوت و خطاهای خود API (مثل آی‌پی نامعتبر یا محدودیت نرخ درخواست) شناسایی می‌شوند و به‌جای اعلام موفقیت اشتباه، پیام خطای درست نمایش داده می‌شود.
- **🎨 رابط رنگی حرفه‌ای ANSI:** پیام‌های وضعیت و خطا با رنگ‌بندی استاندارد ترمینال تفکیک شده‌اند تا خوانایی به اوج برسد.
- **♿ سازگار با صفحه‌خوان‌ها:** ساختار متنی تمیز و مرتب، کاملاً بهینه‌شده برای کاربران ابزارهای دسترس‌پذیری نظیر TalkBack.

## 🚀 نصب سریع و نحوه استفاده

شما نیازی به دانلود کل مخزن ندارید؛ به راحتی می‌توانید اسکریپت را با یک دستور `curl` دریافت و اجرا کنید:

```bash
# دانلود مستقیم اسکریپت
curl -sO https://raw.githubusercontent.com/alinasrollahzadeh405-sudo/ip2location-cli/main/ip_cli.sh

# دادن دسترسی اجرایی به فایل
chmod +x ip_cli.sh

# اجرای ابزار (حالت تعاملی)
./ip_cli.sh

# یا دادن مستقیم آی‌پی
./ip_cli.sh 8.8.8.8
```

بعد از وارد کردن آی‌پی، یک منوی کوتاه برای انتخاب فرمت خروجی نمایش داده می‌شود:

| گزینه | خروجی |
| ----- | ----- |
| `1` (پیش‌فرض) | جیسون مرتب و خوانا با `jq` (پیشنهادی) |
| `2` | خروجی خام API |

اگر بدون تایپ چیزی Enter بزنید، گزینه‌ی ۱ انتخاب می‌شود. اگر `jq` نصب نباشد، ابزار خودکار به خروجی خام برمی‌گردد.

## 📋 پیش‌نیازها

مطمئن شوید ابزارهای زیر روی سیستم شما نصب هستند:
- پوسته `bash` (نسخه ۴ به بالا)
- ابزار ارتباطی `curl`
- ابزار `jq` *(اختیاری، فقط برای خروجی مرتب لازم است)*

نصب `jq`:

```bash
# دبیان / اوبونتو / کالی
sudo apt install jq

# فدورا
sudo dnf install jq

# آرچ
sudo pacman -S jq

# مک (Homebrew)
brew install jq

# ترموکس (اندروید)
pkg install jq
```

## ⚠️ نکات و عیب‌یابی

- **محدودیت نرخ درخواست:** API بدون کلید یک سقف روزانه برای تعداد درخواست دارد. اگر به آن برسید، ابزار به‌جای نتیجه، پیام خطای API را نشان می‌دهد. بعداً دوباره امتحان کنید.
- **فرمت نامعتبر آی‌پی:** مطمئن شوید یک آدرس IPv4 (مثل `8.8.8.8`) یا IPv6 معتبر وارد کرده‌اید.
- **خطای اتصال:** درخواست بعد از ۱۰ ثانیه تایم‌اوت می‌شود. اتصال اینترنت را بررسی کنید و دوباره تلاش کنید.
