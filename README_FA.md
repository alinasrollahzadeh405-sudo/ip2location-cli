# ابزار خط فرمان ip2location-cli 🚀

ابزار `ip2location-cli` یک اسکریپت سبک، حرفه‌ای و بدون مانع بر پایه پوسته (Bash CLI) است که برای توسعه‌دهندگان، مهندسان شبکه و مدیران سیستم طراحی شده است. این ابزار به شما اجازه می‌دهد در سریع‌ترین زمان ممکن، اطلاعات جغرافیایی IP، مشخصات ISP و بررسی‌های امنیتی (مانند تشخیص پروکسی و VPN) را مستقیماً از طریق ترمینال و با استفاده از API بدون کلید IP2Location انجام دهید.

بدون نیاز به ساخت اکانت. بدون نیاز به کلید API. بدون پیچیدگی‌های رابط کاربری گرافیکی. خالص، سریع و قدرتمند در خط فرمان.

---

## ✨ ویژگی‌های کلیدی

- **🔑 دسترسی بدون مانع (Zero-Barrier):** کاملاً بر اساس درخواست‌های Keyless کار می‌کند؛ یعنی نیازی به ثبت‌نام، ایجاد حساب کاربری یا تنظیم کلیدهای سخت‌افزاری و نرم‌افزاری ندارد.
- **⚡ نصب و اجرای تک‌خطی:** نیازی به فرآیندهای طولانی کلون کردن نیست؛ با یک دستور ساده می‌توانید آن را دریافت و اجرا کنید.
- **🛡️ هوش امنیتی و تشخیص تقلب:** شناسایی وضعیت پروکسی، وی‌پی‌ان و اطلاعات مربوط به ریسک شبکه جهت تحلیل‌های سریع.
- **🧼 خروجی خالص جیسون (Raw JSON):** پاسخ سرور دست‌نخورده باقی می‌ماند تا بتوانید به راحتی آن را به ابزارهای دیگر مانند `jq` یا اسکریپت‌های لاگ‌گیری پایپ (Pipe) کنید.
- **🎨 رابط رنگی حرفه‌ای ANSI:** پیام‌های وضعیت و خطا با رنگ‌بندی استاندارد ترمینال تفکیک شده‌اند تا خوانایی به اوج برسد.
- **♿ سازگار با صفحه‌خوان‌ها:** ساختار متنی تمیز و مرتب، کاملاً بهینه‌شده برای کاربران ابزارهای دسترس‌پذیری نظیر TalkBack.

---

## 🚀 نصب سریع و نحوه استفاده

شما نیازی به دانلود کل مخزن ندارید؛ به راحتی می‌توانید اسکریپت را با یک دستور `curl` دریافت و اجرا کنید:

```bash
# دانلود مستقیم اسکریپت
curl -sO https://raw.githubusercontent.com/alinasrollahzadeh405-sudo/ip2location-cli/main/ip_cli.sh

# دادن دسترسی اجرایی به فایل
chmod +x ip_cli.sh

# اجرای ابزار
./ip_cli.sh
```
